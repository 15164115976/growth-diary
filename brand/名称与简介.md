# 春生夏长 · 名称与文案

## 主推名称

# 春生夏长

> 出自《史记·太史公自序》：「夫春生夏长，秋收冬藏，此天道之大经也。」

**为什么是它：**

- 四个字全是大白话，不用解释就懂，底子却出自《史记》，不轻浮
- 讲的正是时序——春天生发、夏天长成，对应「一天一张、跟着季节走」的记录方式
- 「秋收冬藏」天然接在后面，暗示这条记录线会一直走下去，不是记几天就扔的
- 和界面里「第 N 天」的气质是一路的

**英文副标**：GROWTH DIARY（界面顶部已在用）

## 备选名称

| 名称 | 出处 | 适合什么调性 | 顾虑 |
|---|---|---|---|
| **生生不息** | 《易经·系辞》「生生之谓易」 | 最直白，人人都懂，正面积极 | 重名概率高，稍常见 |
| **日就月将** | 《诗经·周颂·敬之》「日就月将，学有缉熙于光明」 | 每天有进、每月有成，最贴「日更」这件事 | 偏文雅，第一眼要解释 |
| **葳蕤** | 《孔雀东南飞》「葳蕤自生光」 | 草木茂盛下垂的样子，两个字最美 | 生僻字影响搜索和口口相传 |
| **拔节** | 竹子在拔节期一夜蹿高一截 | 现代感，动感强，两个字好念 | 略有工业感，少了温润 |

> 小程序名称在微信平台全局唯一。主名被占用就按上表顺延，四个备选都验过语义和出处。

## 简介

微信后台「简介」字段限 **4–120 字**，下面两版按需取用。

### 完整版（约 100 字）

```
为花、鸟、鱼、虫各建一条记录线。每天同一角度拍一张，取景时会自动叠上
上次的照片帮你对齐；养护手册和打卡日志分开记；所有照片按时间连成一段
可以播放的成长影像。日子久了，才看得出它们究竟长了多少。
```

### 精简版（约 45 字）

```
给花鸟鱼虫拍生长日记：每天一张同角度照片，配上养护手册与打卡记录，
最后连成一段会动的成长影像。
```

### 一句话 slogan

```
一天一张，春生夏长。
```

### 分享文案（已写进代码）

- 首页分享：`春生夏长 · 把花鸟鱼虫的日子拍下来`
- 单条记录分享：`{名字} 的生长记录 · 第 N 天`

## 头像

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon-a-sprout.png` | 144×144 | **主推**，微信后台上传这张 |
| `icon-b-paper.png` | 144×144 | 备选：暖纸底，素雅 |
| `icon-c-four.png` | 144×144 | 备选：彩色四点，对应花鸟鱼虫 |
| `icon-a-sprout@4x.png` 等 | 576×576 | 高清源文件，用于海报、启动图、商店素材 |
| `preview-icons.png` | 1080×512 | 三案对比图（含圆形裁切预览） |

**设计说明**

主方案是「年轮细环 + 一枚新芽」：环是时间，芽是生长。环留了呼吸空间，不压迫主体；深苔绿底（`#5CA078 → #244E38` 斜向渐变）在聊天列表的白底上辨识度最高。三张图的主体都压在中部安全区内，无论微信把它裁成圆角矩形还是正圆，都不会切到芽。

**技术处理**：576×576 绘制后 LANCZOS 缩到 144×144，等于 4 倍超采样，所以茎和叶的边缘在小尺寸下没有锯齿。重新生成跑 `python make_icons.py` 即可（需 Pillow）。
